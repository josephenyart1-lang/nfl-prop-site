# NFL prop model — published site

A static page showing predicted passing, receiving and rushing volume for
upcoming NFL games, against the lines on offer.

Four files, no build step, no server, no dependencies. Cloudflare Pages
serves this folder exactly as it is.

## Where it comes from

Generated by `attempts_model/build_site.py` in a separate private
repository, from public [nflverse](https://github.com/nflverse) data.
Only ten fields reach `selections.json`, by allowlist, and the generator
refuses to write the folder at all if it finds a credential or a
sportsbook's own probabilities in its output.

## What this is not

Model predictions, not advice. The model has not been shown to beat a
sportsbook: measured against unseen seasons it is a little better than
guessing a player's recent average and no more, with a typical miss of
about 7.6 pass attempts, 2.4 targets and 5 carries against lines near
33, 5 and 12.

It cannot see an injury, a depth-chart change or a snap count. Where it
disagrees loudly with a line, it is usually the model that is wrong.

Nothing here is a recommendation to bet.
